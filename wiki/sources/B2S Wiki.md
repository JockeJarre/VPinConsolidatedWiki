## Key Takeaways

- B2S Server is the bridge between VPX tables and backglass display
- Dual architecture: DLL (in-process COM) vs EXE (separate process, more features)
- Extensive screen configuration system for single/dual/triple monitor setups
- Plugin architecture connects to DOF and PinUp Player
- Rich VBScript API for table authors (lighting, scoring, animation, sound)
- Configuration hierarchy: global ScreenRes.txt → per-table tablename.res → per-ROM B2STableSettings.xml
