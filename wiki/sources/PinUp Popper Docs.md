# PinUp Popper Docs

PinUp Popper (PUP) is a frontend and media server for virtual pinball cabinets, supporting full-screen video, DMD media, and controller integration.

## Canonical Upstream

- [PinUp Popper Wiki](https://www.nailbuster.com/wikipinup/doku.php?id=start)

## Source Files

Run `update-raw.ps1` to mirror the public PinUp Popper wiki into local HTML snapshots under [raw/PUP/site](../../raw/PUP/site/).

The checked-in repository still only includes [raw/PUP/Documentation.url](../../raw/PUP/Documentation.url); mirrored HTML pages are generated locally and are not committed.

Current snapshot file count: 78 mirrored HTML pages plus [site-index.json](../../raw/PUP/site/site-index.json).

## Key Facts

- PinUp Popper is the primary frontend alternative to PinballX
- Handles table launch, media playback (backglass, DMD, wheel, topper), and B2S plugin integration
- Supports PuPPack media overlays and full scripting
