# DOF Table Configuration

DOF table configuration determines how game events in [Visual Pinball X](../projects/Visual%20Pinball%20X.md) map to physical feedback effects via the [DirectOutput Framework](../projects/DirectOutput%20Framework.md). It's the link between what happens on-screen and what happens in the [pincab](Pincab%20Setup.md).

## Configuration Methods

### 1. XML Table Config (Most Powerful)

Per-table XML files defining table elements, effects, and assignments:

```xml
<Table>
  <TableName>My Table</TableName>
  <TableElements>
    <TableElement>
      <TableElementType>Solenoid</TableElementType>
      <Number>1</Number>
      <AssignedEffects>
        <AssignedEffect>
          <EffectName>Left Flipper Kick</EffectName>
        </AssignedEffect>
      </AssignedEffects>
    </TableElement>
  </TableElements>
  <Effects>
    <DurationEffect>
      <EffectName>Left Flipper Kick</EffectName>
      <ToyName>Left Flipper Contactor</ToyName>
      <Duration>100</Duration>
    </DurationEffect>
  </Effects>
  <AssignedStaticEffects>
    <!-- Effects on table init (e.g., illuminate start button) -->
  </AssignedStaticEffects>
</Table>
```

### 2. INI Files (Legacy)

`directoutputconfig.ini` files with `[Config DOF]` sections. ROM name rows with 32+ columns for LedWizEquivalent outputs. Generated by the **DOF Config Tool** at vpuniverse.com.

### 3. Hybrid

Mix XML effects for advanced behavior with INI for standard gadgets.

## Workflow: Solid State (ROM) Tables

For tables using PinMAME ROM emulation:

1. Replace `CreateObject("VPinMAME.Controller")` with `CreateObject("B2S.Server")` in the table [script](../concepts/VPX%20Scripting.md)
2. PinMAME data automatically flows: ROM → PinMAME → [B2S Server](../projects/B2S%20Backglass%20Server.md) → DOF
3. DOF matches table element numbers to effects in the config file matching the ROM name

## Workflow: EM / Original Tables

For tables without ROM emulation:

```vbscript
Dim Controller
Set Controller = CreateObject("B2S.Server")
Controller.B2SName = "MyTable"   ' Fake ROM name
Controller.Run

' During gameplay:
Controller.B2SSetData 205, 1     ' Activate element 205
Controller.B2SSetData 205, 0     ' Deactivate

' Helper for pulsing:
Sub DOF(id, val)
  Controller.B2SSetData id, val
  Controller.B2SSetData id, 0
End Sub
```

Add `Controller.Stop` to `Table_Exit` event.

## Table Element Types

| Type | Description |
|------|-------------|
| **Solenoid** | Flipper coils, pop bumpers, slingshots |
| **Lamp** | Playfield inserts and backbox lamps |
| **Switch** | Physical switches triggered by ball/player |

## INI Format Details

Columns are numbered by [output controller](../concepts/DOF%20Output%20Controllers.md):
- 1–16: LedWiz units
- 19: PacDrive
- 20–27: PacLed64 units
- 30+: Custom controllers

Settings per column include: trigger parameters (S48, W32, L59), colors, intensity, wait/delay, fade duration, blink, layer, and matrix area.
